Questions and ideas I'm circling. Not essays — containers.

A thread has no end. It collects: quotes, books, videos, my own notes.
I never tidy this page. Things link *to* a thread, and the backlinks
panel on that thread assembles itself.

**Thread vs note:** a note says something. A thread asks something, or
holds something I'm still turning over.

**Thread vs project:** a project ends (Sept 15). A thread doesn't.
